Wi-Fi permission required

Android requires permission before nearby Wi-Fi networks can be discovered.

info

Nearby Wi-Fi devices and location permissions are required by the Android 802.11 scan API to receive broadcast beacon frames.

Since Android 10, the operating system classifies Wi-Fi scanning as potential geolocating telemetry because public BSSIDs correspond directly to physical access points.

Android 13 introduced NEARBY_WIFI_DEVICES with a neverForLocation flag, allowing high-speed layer-2 frame captures without tracking physical coordinates.
