## 1. Scope & Dedicated Purpose

**WPS/A Tester** is an open-source technical security auditing tool designed for:
1. **Network Administrators & Security Engineers**: Auditing Wi-Fi routers and access points to verify whether Wi-Fi Protected Setup (WPS) is enabled, vulnerable to implementation bugs, or properly disabled.
2. **Defensive Testing**: Evaluating whether a router's Push Button Configuration (PBC) responds properly within the 120-second association window.
3. **Hardware & Environment Diagnostics**: Inspecting low-level Linux networking subsystem interfaces, SELinux policies, and `wpa_supplicant` hardware control sockets on rooted Android devices.
4. **Educational & Research Applications**: Understanding modern Android Wi-Fi architecture, root-level supplicant interaction, and 802.11 protocol dynamics.

### What This Software Does NOT Do
To maintain ethical standards and prevent malicious exploitation, WPS/A Tester:
- **Does NOT** include automated PIN brute-forcing or dictionary attack modules.
- **Does NOT** incorporate Pixie Dust attack tools.
- **Does NOT** contain pre-compiled default PIN databases or manufacturer backdoor tables.
- **Does NOT** harvest, export, or steal saved WPA/WPA2/WPA3 network passwords.
- **Does NOT** perform packet injection or denial-of-service (DoS) attacks.
